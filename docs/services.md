# Services

LogiMentor offers commercial support for `lm_memories`, including:

- FPGA integration support.
- Vendor-specific validation.
- Custom memory and FIFO development.
- Porting legacy memory generators into `lm_memgen`.
- Project-specific simulation and synthesis smoke-test setup.

The open-source library remains Apache-2.0 licensed and suitable for commercial
and academic FPGA projects.
